# Apple Toss

Небольшая 2D-игра в стиле аркады, написанная на Java Swing.  
Твоя задача — выбрать угол и силу броска, метнуть яблоко и попасть в дерево, набирая очки.

## Описание проекта

Это небольшая учебная игра про бросание яблок.  
Игрок управляет силой и направлением броска, а затем следит за траекторией яблока в реальном времени.

Игра включает:
- простой игровой цикл и анимацию;
- физику броска и гравитацию;
- систему очков;
- простое 2D-рисование в Swing;
- интуитивное управление клавиатурой.

## Управление

- Left / Right — изменить угол броска
- Up / Down — увеличить или уменьшить силу броска
- Space — бросить яблоко

## Как запустить

Требования:
- JDK 8 или выше

Запуск через IDE:
1. Открой проект в IntelliJ IDEA / Eclipse / VS Code
2. Запусти класс `com.game.Main`

Запуск через терминал:
```bash
bash javac src/main/java/com/game/.java java -cp src/main/java com.game.Main
```
